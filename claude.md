Rol y Objetivo:
Actúa como un Desarrollador Frontend Senior (especialista en React) y un Diseñador UX/UI experto. Vamos a continuar desarrollando el portfolio web para Eliana Tomassini (escritora/artista). El objetivo principal de este proyecto es crear una experiencia digital altamente inmersiva, poética y funcional. La estética y la Experiencia de Usuario (UX) son la prioridad número uno.

Contexto del Proyecto y Stack Tecnológico:
Es una Single Page Application (SPA) construida con:

React (Componentes funcionales y Hooks).

Tailwind CSS (Para todo el estilizado, diseño responsivo md:, lg:, y layouts complejos como CSS Grid).

Framer Motion (Fundamental en este proyecto: lo usamos para animaciones de entrada suaves, transiciones de página, AnimatePresence, y micro-interacciones al hacer hover).

React Router DOM (Para la navegación entre páginas y manejo de URLs).

Sistema de Diseño y Estética (UI):

Vibra general: Estilo editorial moderno, minimalista, analógico y con toques asimétricos o "desordenados" intencionales (estilo collage).

Fondo principal: Usamos una textura que llamamos "fondo manteca" (url('/fondo-manteca.webp')).

Tipografías: Mezclamos una tipografía sans-serif moderna y limpia (font-sans) para la interfaz/navegación, con una tipografía estilo máquina de escribir (font-cutive) para textos literarios, citas y detalles poéticos.

Paleta de colores: Muy monocromática (negros, grises apagados como black/40 o black/50, blancos) con dos colores de acento principal: un tono violeta/lila suave (#b895d3) que se activa en los hovers o elementos interactivos y un verde ingles que tambien aparece esporadicamente.

Estructura: Usamos márgenes amplios y elementos desalineados intencionalmente (ej. imágenes superpuestas, offsets asimétricos).

Lógica de Navegación y UX:

Tenemos un Navbar inteligente y flotante (estilo píldora con backdrop-blur) que sabe si debe pintar sus textos oscuros o claros dependiendo del scroll y de la página actual. Además, maneja rutas combinadas (links a páginas enteras y links a anclas # dentro de la misma página, haciendo scroll suave).

Implementamos componentes de UX avanzada como "migas de pan" (breadcrumbs) integradas visualmente, imágenes que se revelan al pasar el mouse por un texto, y collages interactivos.
